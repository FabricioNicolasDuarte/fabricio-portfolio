skadia-data-engineering

Medallion pipeline · precision livestock

Orquestación Airflow, transformaciones PySpark sobre Delta Lake (bronze / silver / gold) y ejecución equivalente en Databricks Free Edition o Spark local[*]. Hechos: pesadas, rodeos, ITH horario, BCS, eventos sanitarios, ocupación diaria. Serving: ADG, carga UA/ha, horas ITH en riesgo, % BCS < 4.

Especificación

IngestaPlanillas CSV (;, dd/MM/yyyy). Corrección de pesada: mismo pesada_id, gana captured_at máximo (MERGE).
BronzeDelta, overwrite de partición ingest_date. Sin pérdida de filas sucias.
SilverContrato de rangos; cuarentena; late-arriving = captura > event_ts + 24 h.
QualityGates sobre PK, nulos, BCS 1–9, ITH físico, ratio late-arriving. Fallo aborta gold.
Gold ADGGap mínimo 7 días, clip (−1.2, 2.4) kg/d, exclusión en ventana de retiro sanitario.
CargaΣ UA-día / (ha útil × días de la ventana), no cabezas/ha puntuales.
RuntimeDAG skadia_medallion_ganaderia. Spark driver 4 GB. Default 2 000 animales × 90 días.

Reproducir en workstation

Todo el runtime está en el repositorio (Compose, jobs, DAG, dashboard). No hace falta Databricks para la corrida local.

github.com/FabricioNicolasDuarte/skadia-data-engineering

git clone https://github.com/FabricioNicolasDuarte/skadia-data-engineering.git

docker compose up -d --build && docker compose run --rm pipeline run-all

Airflow: http://localhost:8088 (admin/admin). Streamlit: http://localhost:8501. Requisitos: Docker Desktop, ~4 GB RAM.
